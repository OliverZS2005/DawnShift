# ClaudeCodeIsTuff

## [minecraft-skin-3d-converter](minecraft-skin-3d-converter/)

Turns a Minecraft skin texture into a 3D-printable model (STL, or OBJ+MTL
with the full-color texture) right in the browser. See its
[README](minecraft-skin-3d-converter/README.md) for details.

## [botcrew](botcrew/)

A team of AI coworkers that runs on your own computer, like SpaceXAI's Grok
Bot but for any AI: each bot can use Claude, ChatGPT, Grok, Gemini,
OpenRouter or a local model (Ollama, LM Studio). Bots have jobs, remember
things, hand work to each other, ask before risky actions, and run recurring
routines. See its [README](botcrew/README.md) to get started.
